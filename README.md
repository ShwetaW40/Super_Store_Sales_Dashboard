# Super Store Sales Dashboard | Microsoft Excel

## Project Overview
An interactive sales analytics dashboard developed using Microsoft Excel to monitor business performance and explore sales trends across regions, cities, product categories, shipping modes, and customer segments.

## Dashboard Features
- **KPI Metrics:** Total Sales, Average Sales, Transactions, and Total Quantity.
- **Shipping Analysis:** Sales percentage by shipping mode.
- **Regional Analysis:** Transaction distribution across Central, East, South, and West.
- **Monthly Trends:** Monthly quantity ordered.
- **City Analysis:** Top five cities by sales.
- **Category Analysis:** Transactions by product category.
- **Customer Segments:** Quantity ordered by Consumer, Corporate, and Home Office segments.
- **Interactive Filters:** Region and year slicers.

## Tools & Skills
- Microsoft Excel
- Data Cleaning and Analysis
- Pivot Tables and Charts
- Interactive Dashboard Design
- KPI Reporting and Data Visualization
